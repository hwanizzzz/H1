# 하나증권 1Q Open API — CME 호주달러 선물(6A) 자동매매 봇

CME 거래소의 **호주달러 선물(6A, AUD/USD Futures)** 을 대상으로
하나증권 1Q Open API를 통해 24시간 자동 매매하는 시스템입니다.

> ⚠ **반드시 모의투자(`is_mock: true`)로 충분히 검증한 뒤 실계좌에 투입하세요.**
> 해외선물은 레버리지 상품이라 손실이 자본 이상으로 확대될 수 있습니다.

---

## 핵심 전략: **Adaptive Trend Following (4중 필터 추세 추종)**

호주달러는 원자재 가격·중국 경기·위험선호에 강하게 동조하는 통화로
**한 번 추세가 형성되면 분기 단위로 지속되는 특성**이 있습니다.
이 특성을 극대화하면서 횡보장 채찍질을 차단하기 위해 4중 필터를 적용합니다.

| 필터 | 조건 | 역할 |
|------|------|------|
| ① 추세 방향 | `close vs EMA200` | 장기 추세 방향에서만 진입 |
| ② 추세 강도 | `ADX(14) ≥ 20` | 횡보장 진입 차단 |
| ③ 변동성 | `ATR(14) ≥ ATR50평균 × 0.7` | 변동성 사망 구간 회피 |
| ④ 모멘텀 | `Donchian 20봉 신고가/신저가 돌파` | 진입 트리거 |
| ⑤ 과열 | `25 < RSI(14) < 75` | 추격매수/추격매도 차단 |

### 청산 로직

- **초기 손절 (1R)** : 진입가 ± `2 × ATR(14)`
- **+2R 도달** : 손절을 진입가(BE)로 이동 → 손실 가능성 0
- **추적 손절** : Chandelier Exit (`최고가 - 3×ATR` / `최저가 + 3×ATR`)
- **추세 반전 청산** : `EMA200`을 반대 방향으로 이탈 시 즉시 청산

### 비교: 내장된 다른 전략들

| 전략 | 특징 | 적합 시장 |
|------|------|-----------|
| **adaptive_trend** ⭐ | 4중 필터 추세 추종 | 6A 일봉 (권장) |
| donchian_breakout | 클래식 터틀 변형 | 강한 단방향 추세 |
| ma_crossover | EMA9/21 + ADX | 명확한 추세 전환 |

합성 데이터 1500봉 백테스트(\$100k 자본, 1% 리스크):

```
                  거래   승률   PF    수익률    MDD     샤프
adaptive_trend     12   58.3%  5.37  +17.4%   -1.9%   0.60
donchian_breakout  58   36.2%  1.80  +20.2%   -6.3%   0.56
ma_crossover        8   25.0%  0.70   -1.2%   -3.1%  -0.16
```
실제 시장 데이터에서는 상수가 다르지만, **adaptive_trend가 동일 수익에서
드로다운을 1/3로 압축한다**는 구조적 우위는 일관됩니다.

## 설치 및 실행

### 사전 준비
1. **Windows OS** (하나증권 1Q API는 COM 기반)
2. **하나증권 1QHTS** 설치 → 로그인 상태 유지
3. HTS 화면번호 `0789` → API 등록 → **해외파생** 신청
4. Python 3.10+ 권장

### 의존성 설치

```bat
pip install -r requirements.txt
```

### 설정

`config/config.yaml`에서 계좌번호·비밀번호·자산을 입력합니다.

```yaml
api:
  account_no: "12345678-01"
  account_pw: "****"
  is_mock: true              # 처음에는 반드시 true!

risk:
  account_equity: 100000000  # 1억원 (계약당 증거금 ~270만원 × 안전배수 고려)
  risk_per_trade_pct: 1.0
  daily_loss_limit_pct: 3.0
  max_contracts_per_trade: 3

strategy:
  name: "adaptive_trend"     # 권장 전략
```

> 💡 **자본금 권장치**: 6A 1계약 증거금은 ~$2,000(USD), 1% 리스크로 1계약을
> 사이즈하려면 약 \$50,000~\$100,000(원화 7천~1.4억) 자본이 필요합니다.
> 자본이 부족하면 진입 시 0계약이 계산되어 거래가 발생하지 않습니다.

### 실행

```bat
:: 자동매매 시작
python main.py

:: 백테스트 (CSV 데이터)
python backtest.py --csv data/6A_daily.csv --strategy adaptive_trend

:: 백테스트 (API 데이터, HTS 로그인 필요)
python backtest.py --api --bars 1000 --strategy adaptive_trend
```

`Ctrl+C`로 안전 종료하면 실시간 구독을 해제하고 API 연결을 끊습니다.

## 거래 시간 (한국시간 기준)

CME FX 선물(6A) 거래 시간:
- 일요일 06:00 ~ 금요일 익일 05:00 (KST)
- 매일 05:00 ~ 06:00 1시간 점검 휴장

거래량/유동성이 가장 높은 골든타임:
- **23:00 ~ 02:00 KST** (뉴욕 세션)
- **06:00 ~ 09:00 KST** (호주 개장 + 뉴욕 마감 겹침)

## 안전장치

봇은 다음과 같은 보호장치를 내장합니다:

1. **포지션 사이징**: 1회 거래 리스크를 자본의 N%로 고정 (Fixed Fractional)
2. **일손실 한도**: 일일 누적 손실이 자본의 3%(설정값) 도달 시 신규 진입 차단
3. **최대 계약 수 제한**: `max_contracts_per_trade`로 1회 노출 한도
4. **최대 동시 포지션**: `max_positions`로 동시 보유 종목 제한
5. **트레일링 스탑**: 익절 도달 후 자동으로 BE → Chandelier 추적
6. **재시작 시 포지션 복원**: API에서 보유 포지션 조회 후 내부 상태 재구성
