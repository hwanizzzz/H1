# 하나증권 1Q Open API — CME 호주달러 선물(6A) 자동매매 봇

CME 거래소의 **호주달러 선물(6A, AUD/USD Futures)** 을 대상으로
하나증권 1Q Open API를 통해 24시간 자동 매매하는 시스템입니다.

본 봇은 두 가지 운용 모드를 지원합니다:
- **Tier 3 어그레시브** (`multi_tf_aggressive`): 4H+1H 멀티TF + 4단 피라미딩 + 회로차단기
  → 자본 3,000만원 ~ 1억원 + 공격적 운용 시 권장
- **안정형** (`adaptive_trend`): 일봉 4중 필터 추세 추종 → 자본 1억원+ 권장

> ⚠ **반드시 모의투자(`is_mock: true`)로 1개월 이상 검증한 뒤 실계좌에 투입하세요.**
> Tier 3는 단일 트레이드 손실이 자본의 8%까지 도달 가능하며,
> 일시 평가손이 -40%까지 발생할 수 있습니다.

## 🔥 Tier 3 어그레시브: **Multi-Timeframe + Pyramiding**

자본 3,000만원으로 6A를 운용하며 수익률을 극대화하기 위해 설계된 전략입니다.

### 진입 로직 (4H 추세 + 1H 트리거)

| 타임프레임 | 역할 | 조건 |
|---|---|---|
| **4H** | 추세 방향 결정 | EMA50 / EMA200 정렬 + ADX(14) ≥ 18 |
| **1H** | 진입 트리거 | Donchian 20봉 돌파 + RSI(14) 과열 회피 |

→ 4H 추세 방향(롱 후보) + 1H 신고가 돌파 + RSI < 75 = **롱 진입**

### 피라미딩 (Turtle 변형, 최대 4단)

추세가 살아있을 때 포지션을 추가해 큰 추세에서 수익을 극대화:

```
1단: 진입가 (베이스 사이즈 100%)
2단: +0.5×ATR(4H) 도달 → 베이스 75% 추가
3단: +1.0×ATR(4H) 도달 → 베이스 50% 추가
4단: +1.5×ATR(4H) 도달 → 베이스 50% 추가
```

모든 단위는 동일한 추적 손절을 공유하며, 새 단 추가 시 손절도 함께 끌어올립니다.

### 청산 로직

| 조건 | 동작 |
|---|---|
| 초기 손절(1R) | 진입가 ± 1.5 × ATR(4H) |
| **+3R 도달** | 보유의 50% 부분 익절, 잔여는 BE로 이동 |
| Chandelier Exit | 부분익절 후 `최고가 - 3×ATR(4H)` 추적 |
| 4H EMA50 반대 이탈 | 즉시 전량 청산 (추세 반전) |

### 회로차단기 (안전장치)

| 트리거 | 동작 |
|---|---|
| 일일 손실 ≥ 4% | 신규 진입 차단 (당일) |
| 일일 손실 ≥ 6% | **강제 청산 + 24시간 정지** |
| 주간 낙폭 ≥ 12% | **3일간 거래 정지** |
| 5연패 | 24시간 정지 |

회로차단기 발동 시 사용자가 직접 원인 분석 후 `risk.reset_halt()` 또는 봇 재시작으로 해제.

### 자본 적정성

| 항목 | 일봉 1% (기존) | 4H 3% (Tier 3) |
|---|---|---|
| 평균 ATR | 0.0060 | 0.0020 |
| 1R 손절폭 | 120틱 ($1,200) | 30틱 ($300) |
| 3,000만원 자본 1회 리스크 | $214 | $645 |
| 계산 계약수 | **0계약** ❌ | **2계약** ✅ |

## 안정형 전략: **Adaptive Trend Following (4중 필터 추세 추종)**

호주달러는 원자재 가격·중국 경기·위험선호에 강하게 동조하는 통화로
**한 번 추세가 형성되면 분기 단위로 지속되는 특성**이 있습니다.

| 필터 | 조건 | 역할 |
|------|------|------|
| ① 추세 방향 | `close vs EMA200` | 장기 추세 방향에서만 진입 |
| ② 추세 강도 | `ADX(14) ≥ 20` | 횡보장 진입 차단 |
| ③ 변동성 | `ATR(14) ≥ ATR50평균 × 0.7` | 변동성 사망 구간 회피 |
| ④ 모멘텀 | `Donchian 20봉 신고가/신저가 돌파` | 진입 트리거 |
| ⑤ 과열 | `25 < RSI(14) < 75` | 추격매수/추격매도 차단 |

### 청산 로직

- **초기 손절 (1R)** : 진입가 ± `2 × ATR(14)`
- **+2R 도달** : 손절을 진입가(BE)로 이동 → 손실 가능성 0
- **추적 손절** : Chandelier Exit (`최고가 - 3×ATR` / `최저가 + 3×ATR`)
- **추세 반전 청산** : `EMA200`을 반대 방향으로 이탈 시 즉시 청산

### 전략 비교

| 전략 | 자본 권장 | 거래 빈도 | 특징 |
|---|---|---|---|
| **multi_tf_aggressive** ⭐ | 3천만~1억 | 월 5~25회 | 멀티TF + 피라미딩, Tier 3 |
| **adaptive_trend** | 1억+ | 월 1~2회 | 안정형 일봉 |
| donchian_breakout | 1억+ | 월 2~4회 | 클래식 터틀 |
| ma_crossover | 1억+ | 월 4~8회 | EMA 크로스 |

합성 데이터 1500봉 백테스트(\$100k 자본, 1% 리스크):

```
                  거래   승률   PF    수익률    MDD     샤프
adaptive_trend     12   58.3%  5.37  +17.4%   -1.9%   0.60
donchian_breakout  58   36.2%  1.80  +20.2%   -6.3%   0.56
ma_crossover        8   25.0%  0.70   -1.2%   -3.1%  -0.16
```
실제 시장 데이터에서는 상수가 다르지만, **adaptive_trend가 동일 수익에서
드로다운을 1/3로 압축한다**는 구조적 우위는 일관됩니다.

## 설치 및 실행

### 사전 준비
1. **Windows OS** (하나증권 1Q API는 COM 기반)
2. **하나증권 1QHTS** 설치 → 로그인 상태 유지
3. HTS 화면번호 `0789` → API 등록 → **해외파생** 신청
4. Python 3.10+ 권장

### 의존성 설치

```bat
pip install -r requirements.txt
```

### 설정 (Tier 3 어그레시브 — 3,000만원 자본)

`config/config.yaml`을 다음과 같이 수정합니다:

```yaml
api:
  account_no: "12345678-01"
  account_pw: "****"
  is_mock: true              # 처음에는 반드시 true!

risk:
  account_equity: 30000000   # 3,000만원
  risk_per_trade_pct: 3.0    # Tier 3 어그레시브
  daily_loss_limit_pct: 4.0
  daily_circuit_breaker_pct: 6.0
  weekly_drawdown_limit_pct: 12.0
  consecutive_loss_halt: 5
  max_contracts_per_trade: 8

strategy:
  name: "multi_tf_aggressive"  # ⭐ Tier 3 권장
```

### 설정 (안정형 — 1억원 자본)

```yaml
risk:
  account_equity: 100000000   # 1억원
  risk_per_trade_pct: 1.0
  daily_loss_limit_pct: 3.0

strategy:
  name: "adaptive_trend"
```

> 💡 **자본금별 권장 모드**:
> - **3,000만원~1억원**: `multi_tf_aggressive` (4H+1H 멀티TF, 4단 피라미딩)
> - **1억원 이상**: `adaptive_trend` (일봉, 안정성 우선)
> - 자본이 부족한 상태에서 일봉 1% 리스크 모드를 쓰면 진입 0계약이 계산되어
>   거래가 발생하지 않습니다.

### 실행

```bat
:: 자동매매 시작
python main.py

:: 백테스트 — 멀티TF 어그레시브 (1H 분봉 CSV 필요)
python backtest.py --csv data/6A_1h.csv --tf 1H --strategy multi_tf_aggressive --equity 21500 --risk 3.0

:: 백테스트 — 안정형 (일봉)
python backtest.py --csv data/6A_daily.csv --strategy adaptive_trend --equity 71000

:: 백테스트 — API에서 자동 수신 (HTS 로그인 필요)
python backtest.py --api --bars 5000 --tf 1H --strategy multi_tf_aggressive

:: 단위 테스트 실행
python -m unittest tests.test_aggressive -v
```

`Ctrl+C`로 안전 종료하면 실시간 구독을 해제하고 API 연결을 끊습니다.

## 거래 시간 (한국시간 기준)

CME FX 선물(6A) 거래 시간:
- 일요일 06:00 ~ 금요일 익일 05:00 (KST)
- 매일 05:00 ~ 06:00 1시간 점검 휴장

거래량/유동성이 가장 높은 골든타임:
- **23:00 ~ 02:00 KST** (뉴욕 세션)
- **06:00 ~ 09:00 KST** (호주 개장 + 뉴욕 마감 겹침)

## 안전장치 (Tier 3 강화)

봇은 다음과 같은 다층 보호장치를 내장합니다:

1. **포지션 사이징**: 1회 거래 리스크를 자본의 N%로 고정 (Fixed Fractional)
2. **피라미드 사이즈 감쇠**: 단위가 늘수록 추가분 사이즈 축소(1.0→0.75→0.5→0.5)
3. **일손실 한도**: 일일 손실 4% 도달 시 신규 진입 차단
4. **일일 회로차단기**: 일일 손실 6% 도달 시 **즉시 강제 청산 + 24시간 정지**
5. **주간 낙폭 차단기**: 주간 -12% 도달 시 3일 거래 정지
6. **연속 손실 차단기**: 5연패 시 24시간 정지 (전략 자체 결함 의심)
7. **최대 계약 수 제한**: `max_contracts_per_trade`로 노출 한도
8. **트레일링 스탑**: 익절 도달 후 자동으로 BE → Chandelier 추적
9. **재시작 시 포지션 복원**: API에서 보유 포지션 조회 후 내부 상태 재구성

회로차단기가 발동되면 사용자가 원인 분석 후 `risk.reset_halt()` 또는 봇 재시작으로 해제.
